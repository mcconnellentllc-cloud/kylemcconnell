Kyle McConnell

Farmer. Rancher. Business owner. Self-taught developer. Songwriter.

I am the fourth generation of my family to farm and ranch this ground in northeast Colorado. Alongside the operation I run several ag businesses, and I write the software they depend on.

Nobody taught me to code. I started building because the tools our operation needed did not exist, and I kept going because the ones I built worked. Everything listed on this page is running software that real operations use every day.
